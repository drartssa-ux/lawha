رفع «لوحة التحدي» على موقع مجاني (Render)
=========================================
تحتاج حوالي 15 دقيقة، ومرة وحدة بس. في النهاية يصير عندك رابط مثل:
   https://lawha-altahaddi.onrender.com

الخطوة 1: حساب GitHub (مكان تحط فيه ملفات اللعبة)
   1. ادخل github.com وسوّ حساب مجاني (Sign up).
   2. اضغط «+» فوق يمين ← «New repository».
   3. الاسم: lawha  ← خلّه Public ← اضغط «Create repository».
   4. في صفحة المستودع اضغط «uploading an existing file».
   5. فك ضغط ملف اللعبة على جهازك، واسحب كل الملفات والمجلدات اللي داخله
      (index.html و server.py و render.yaml و requirements.txt … إلخ) وأفلتها في الصفحة.
      مهم: اسحب الملفات نفسها، مو المجلد اللي فوقها.
   6. اضغط «Commit changes».

الخطوة 2: حساب Render (اللي يشغّل اللعبة كموقع)
   1. ادخل render.com ← «Get Started» ← سجّل دخول بحساب GitHub نفسه.
   2. اضغط «New +» ← «Blueprint».
   3. اختر المستودع lawha ← اضغط «Connect».
      (إذا ما طلع، اضغط «Configure GitHub» واسمح لـ Render يشوف المستودع)
   4. Render يقرأ ملف render.yaml لحاله. اضغط «Apply» أو «Deploy Blueprint».
   5. انتظر 2-3 دقائق لين يصير «Live» باللون الأخضر.
   6. فوق يطلع رابط موقعك. هذا رابط اللعبة! افتحه على اللابتوب/التلفزيون.

   (طريقة بديلة إذا ما ظهر Blueprint: «New +» ← «Web Service» ← اختر المستودع،
    وحط: Runtime = Python 3 ، Build Command = pip install -r requirements.txt ،
    Start Command = python server.py ، Instance Type = Free ← «Create Web Service».)

ملاحظات مهمة عن الخطة المجانية:
   - إذا ما أحد فتح الموقع 15 دقيقة، «ينام». أول ما تفتحونه يحتاج حوالي دقيقة يصحى.
     افتحوا الرابط قبل اللعب بدقيقة.
   - إذا نام السيرفر أو أعاد التشغيل وسط اللعب، الشاشة الكبيرة تفتح غرفة جديدة لحالها،
     بس لازم الفرق والمقدّم يصوّرون الـQR الجديد.
   - أي أحد معه رابط الموقع يقدر يفتح لعبة لمجموعته. كل مجموعة لها غرفة ورمز خاص،
     وما تتداخل اللعب مع بعض.

تحديث الأسئلة بعدين:
   عدّل ملفات مجلد questions على جهازك، وشغّل  python3 build.py ،
   وبعدها ارفع index.html الجديد على GitHub (Add file ← Upload files ← Commit).
   Render يحدّث الموقع لحاله خلال دقائق.
